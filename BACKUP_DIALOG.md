📌 ОПИСАНИЕ ПРОЕКТА
Telegram-бот для расчета стоимости проектирования мебели (кухни и шкафы).


🏗️ АРХИТЕКТУРА
Основные сущности:
Кухня — категории: верхние ящики, нижние ящики, пеналы

Шкаф — каркасы: стандартный, компактный, увеличенный

Дополнительные услуги — подсветка + 5 допов

Гола — Да/Нет (только для кухни)

Хранение данных в состоянии FSM:

🔧 ОСНОВНЫЕ ИСПРАВЛЕНИЯ И ДОРАБОТКИ
1. Добавление нескольких шкафов и кухонь
Вместо одного шкафа/кухни теперь хранятся списки wardrobe_items и kitchen_items

Каждый шкаф получает номер (Шкаф №1, №2 и т.д.)

Каждая кухня получает номер (Кухня №1, №2 и т.д.)

2. Кнопка "Добавить детали"
Показывает меню с выбором:

🍳 Новая кухня

📦 Добавить к кухне №1, №2... (если есть сохранённые кухни)

🚪 Новый шкаф

📦 Добавить к шкафу №1, №2... (если есть сохранённые шкафы)

🔙 Назад к результату

3. Общая смета
Показывает все сохранённые кухни и шкафы

Подсчитывает общую сумму

4. Кнопки управления
"Продолжить выбор" — возврат в главное меню без сброса данных

"Новый расчет" — полный сброс всех данных

"Главное меню" — возврат в главное меню
